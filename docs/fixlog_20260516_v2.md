## 修复列表

### 检测器规则 enabled 禁用不生效

**问题**: 在前端禁用某条内置规则（enabled=false）或添加自定义规则后，对实际检测行为无效——被禁用的规则仍会触发拦截，自定义规则不会参与检测。

**根因**: 
1. 所有检测器使用硬编码规则（编译时嵌入 `patterns []*regexp.Regexp`），不从数据库读取规则执行检测
2. `ToggleRule()`/`AddCustomRule()`/`RemoveRule()` API 只更新数据库，不同步到检测引擎内存
3. 数据库 `detection_rules` 表仅用于前端展示，与实际检测逻辑完全脱节

**修复方案**: 规则数据库驱动 + 热加载

1. **每个检测器添加 `setPatterns()` 方法**：支持运行时替换内存中的规则列表，通过写锁保证并发安全
2. **Manager 添加 `ReloadRules(detectorType, rules)` 方法**：从 DetectionRule 列表编译正则（过滤 enabled=false），通过 switch 设置到对应检测器
3. **Manager 添加 `LoadAllRulesFromDB(cm)` 方法**：启动时从数据库加载所有检测器的规则到内存
4. **API 层实时同步**：ToggleRule/AddCustomRule/RemoveRule 操作后立即调用 ReloadRules 重新加载
5. **ConfigManager 添加 `GetRuleByID()` 方法**：ToggleRule 时获取规则所属的检测器类型
6. **RemoveRule 改为返回 detectorType**：方便 RemoveRule 后重新加载对应检测器的规则
7. **AppDeps 添加 DetectorManager 字段**：Handler 层可访问 Manager 进行规则热加载
