说明：

1. 限流键类型：选择哪种维度进行限流

2. IP：按客户端IP地址限流（默认）

3. Session：按Session ID限流

4. API Key：按请求头中的API Key限流

5. Cookie：按指定Cookie值限流

6. Header：按指定请求头限流

7. Combined：IP + Session组合限流

示例：

• QPS=100, Burst=200：每个限流键每秒最多100个请求，最多突发200个请求

• 如果QPS或Burst为0，表示不进行限流，所有请求都会通过
